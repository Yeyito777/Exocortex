Run a shell command on one of the user's own machines (such as their laptop), not on this host. Uses bash (PowerShell on Windows) and returns stdout and stderr. Works while that machine is connected: its Exocortex daemon linked to this one, or its TUI over /ssh. Set host to the machine's client ID from the latest notice about the user's machines (e.g. mac); it may be left out only while one machine is connected, and a call never runs on a machine it did not name. Starts in the user's home directory unless cwd is set; a ~ prefix is expanded.
